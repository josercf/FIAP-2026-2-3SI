PRD, SDD & Domain-Driven Design (DDD)

PRD (Product Requirement)

Define O QUE construir: visão do produto, casos de uso, regras de negócio e critérios de aceite.

SDD (System Design)

Define COMO construir: arquitetura técnica, modelo de dados, protocolos, infraestrutura e SLAs.

Bounded Contexts (DDD)

Fronteiras explícitas de domínio: Pedidos, Faturamento, Telemetria e Atendimento IA.

Linguagem Ubíqua

Vocabulário único compartilhado entre especialistas de negócio e desenvolvedores.

SDLC & Versionamento com Git

No ciclo de vida de software corporativo (SDLC), o versionamento com Git é o pilar de rastreabilidade e governança:

# Boas Práticas de Commits (Conventional Commits)
git commit -m "feat(telemetry): add TCP socket listener for truck sensors"
git commit -m "docs(prd): initial PRD and SDD specification for LogiTech"
git commit -m "fix(socket): handle client disconnection gracefully"

Workflows recomendados: Trunk-Based Development para entregas rápidas ou GitFlow para lançamentos com esteira de aprovação via Pull Requests.

TCP vs UDP: Quando Usar Cada Um?

TCP (Transmission Control Protocol)

Orientado à conexão (3-Way Handshake: SYN, SYN-ACK, ACK). Garante entrega na ordem correta, retransmite pacotes perdidos e controla fluxo.

Uso no Case: Confirmações de entrega de frete e notas fiscais.

UDP (User Datagram Protocol)

Sem conexão, sem handshake e sem garantia de entrega. Prioriza velocidade mínima e latência baixa (fire and forget).

Uso no Case: Telemetria frequente de GPS e temperatura de frotas.

# Exemplo de Socket Server TCP em Python
import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(('0.0.0.0', 8080))
server.listen(5)
print("🚛 LogiTech Telemetry TCP Server listening on port 8080...")

while True:
    client, addr = server.accept()
    data = client.recv(1024)
    print(f"Received payload from {addr}: {data.decode('utf-8')}")
    client.send(b"ACK: Telemetry Recorded\n")
    client.close()
