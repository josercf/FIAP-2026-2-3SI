Hands-on Lab: LogiTech Enterprise

Missão

Subir uma infraestrutura completa (API + Redis) e criar um Facade para IA.

Passo a Passo

1. Criar `docker-compose.yml`
2. Definir o serviço web e redis
3. `docker compose up -d`.

# docker-compose.yml
version: '3.8'
services:
  web:
    build: .
    ports:
      - "8000:8000"
    environment:
      - REDIS_HOST=redis
    depends_on:
      - redis
  redis:
    image: "redis:alpine"
    ports:
      - "6379:6379"
