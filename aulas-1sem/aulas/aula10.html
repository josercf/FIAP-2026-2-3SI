Test-Driven Development (TDD)

Red (Vermelho)

Escreva um teste que falha para uma funcionalidade que ainda não existe.

Green (Verde)

Escreva o mínimo de código necessário para o teste passar.

Refactor (Refatorar)

Melhore o código sem alterar seu comportamento, mantendo os testes passando.
