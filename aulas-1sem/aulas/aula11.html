O que caracteriza o Design Pattern Observer?
  • A A criação restrita de instâncias únicas (Singleton).
  • B Um objeto (Subject) notifica múltiplos dependentes (Observers) sobre mudanças de estado.
  • C O uso de middlewares para tratar requisições HTTP.
  • D A componentização de interfaces de usuário.

Programação Reativa com RxJS

import { Observable } from 'rxjs';

// Serviço LogiTech de Telemetria
export class TelemetryService {
  getSpeedData(): Observable<number> {
    return new Observable(subscriber => {
      setInterval(() => subscriber.next(Math.random() * 100), 2000);
    });
  }
}

Quiz #2

No Angular e RxJS, o que deve ser feito com uma Subscription ao destruir o componente?
  • A Nada, o Garbage Collector do JavaScript cuida disso imediatamente.
  • B Chamar `unsubscribe()` no método `ngOnDestroy` para evitar vazamentos de memória (memory leaks).
  • C Reiniciar o servidor de aplicação.
  • D Despachar uma ação no Redux.

Quiz #3

Para que serve o operador `map` no RxJS?
  • A Para criar mapas geográficos na tela.
  • B Para cancelar assinaturas.
  • C Para transformar os dados emitidos pelo Observable antes que cheguem ao subscriber.
  • D Para enviar dados via requisição POST.
