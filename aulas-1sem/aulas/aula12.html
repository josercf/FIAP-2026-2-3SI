Quiz #1

No contexto de IA Generativa, o que é um Embedding?
  • A Um tipo especial de prompt que ignora os limites de tokens da LLM.
  • B Uma representação matemática em forma de vetor (array de números) que captura o significado semântico de um dado.
  • C O processo de enviar imagens para a API da OpenAI.
  • D Um banco de dados relacional clássico.

☕ Pausa para Café

20h50 – 21h20 (30 minutos)

RAG & Model Context Protocol (MCP)

RAG (Retrieval-Augmented Generation): Buscar dados externos para injetar no contexto da LLM, reduzindo alucinações.

MCP: Padroniza a conexão entre Modelos de IA e Fontes de Dados Corporativas (ex: nosso pgvector da LogiTech).

Quiz #2

O que o pgvector permite fazer dentro do PostgreSQL?
  • A Acelerar consultas JOIN em chaves primárias relacionais.
  • B Armazenar e consultar vetores de embeddings utilizando buscas por similaridade (ex: distância de cosseno).
  • C Substituir o uso de SQL por comandos em Python puro.
  • D Gerar embeddings textuais diretamente no banco sem depender de LLMs externas.

Quiz #3

No pipeline RAG, em que momento ocorre a etapa de "Retrieval" (Recuperação)?
  • A Depois que a resposta final é exibida ao usuário.
  • B Durante o treinamento dos pesos (weights) do modelo na infraestrutura da OpenAI.
  • C Antes de enviar o prompt final à LLM, buscando os documentos relevantes na base vetorial.
  • D Apenas quando ocorre um erro na rede.
