14 – Agenda
4

Sexta, 19h, arena da FIAP

Lia Park estuda no Campus Norte e joga FPS. Ela chega na arena para a final e o sistema faz três besteiras.

  1. A ficha some. Ela se inscreve no balcão. Uma hora depois abre o aplicativo e o sistema diz que ela não existe. No Discord abriram outra ficha, com outro número.
  2. A faixa é chute. O organizador olha o jogo e fala "isso é ouro". O colega do lado fala "é bronze, é amistoso". Não existe conta. Quem grita mais alto define a prioridade.
  3. A TV entrega a Lia. No corredor, a televisão mostra o nome dela, o texto do desafio e a coordenada do ginásio. Qualquer aluno que passa lê isso.

A ArenaLog é o sistema dessa liga universitária. Hoje ele está assim. Vocês consertam as três coisas, nessa ordem. [1]

Missão 2. A ficha da Lia

Arquivo elenco/validar.js. Troquem o corpo de validarAtleta. null significa ficha aceita. Texto significa recusa. Nome de 2 a 80, campus preenchido, canal só APP, ARENA ou DISCORD. CANAIS já existe no arquivo.

function validarAtleta(corpo) {
  if (!corpo || typeof corpo !== "object") return "corpo ausente";
  const nome = typeof corpo.nome === "string" ? corpo.nome.trim() : "";
  if (nome.length < 2 || nome.length > 80) return "nome invalido";
  const campus = typeof corpo.campus === "string" ? corpo.campus.trim() : "";
  if (!campus) return "campus obrigatorio";
  if (!CANAIS.has(corpo.canal)) return "canal invalido";
  return null;
}

Rode node --test elenco/test/validar.test.js. Querem ver pass 5 e fail 0. 150 XP.

Missão 3. A faixa, na função calcular

def calcular(modalidade, campus, serie, tabela, campi_rivais):
    pontos = tabela.pontos_base(modalidade)
    if any(normalizar(nome) == normalizar(campus) for nome in campi_rivais):
        pontos += 2
    if serie:
        pontos += 1
    faixa, janela = faixa_de(pontos)
    return {"pontos": pontos, "faixa": faixa, "janelaHoras": janela}

Missão 5. A série, na função eh_serie

def eh_serie(anterior, modalidade, campus, agora):
    if str(anterior.get("modalidade", "")).upper() != str(modalidade).upper():
        return False
    if normalizar(anterior.get("campus", "")) != normalizar(campus):
        return False
    if anterior.get("status") not in ABERTOS:
        return False
    return (agora - anterior["criado_em"]) < timedelta(hours=48)

Missão 6. A TV, na função agregar

Arquivo placar/agregar.js. Hoje a função devolve a lista inteira, com nome e coordenada. A TV só pode devolver contagem. STATUS e FAIXAS já existem. Chave zerada continua no JSON.

function agregar(desafios, campus) {
  const porStatus = Object.fromEntries(STATUS.map((s) => [s, 0]));
  const porFaixa = Object.fromEntries(FAIXAS.map((f) => [f, 0]));
  for (const item of desafios) {
    if (porStatus[item.status] !== undefined) porStatus[item.status] += 1;
    if (porFaixa[item.faixa] !== undefined) porFaixa[item.faixa] += 1;
  }
  return { campus, porStatus, porFaixa };
}

Dois cuidados antes do boss

A TV não mostra a Lia

O placar devolve campus, cinco contagens de status e quatro contagens de faixa. Não devolve nome, texto, id do atleta, latitude, longitude nem id do jogo. A TV pergunta só para partidas, nunca para o elenco.

Cada programa é um computador

Dentro do container de partidas, localhost é a própria partidas. O elenco é outro computador, e o endereço é http://elenco:8081. localhost só serve na máquina de vocês, para o script do boss. [4]

O banco tem duas gavetas, elenco e partidas. Uma não lê a outra. Vocês não mexem no SQL hoje.
