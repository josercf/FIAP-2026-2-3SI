A Arquitetura LogiTech

1. Fundamentos & Rede

Começamos com Sockets TCP/UDP, subimos para HTTP, REST e gRPC.

2. Backend & Cloud Native

Construímos APIs políglotas (Node, Python, Java) e empacotamos tudo com Docker e Docker Compose.

3. AI-First & RAG

Integramos a LangChain para consultar a Base de Conhecimento e automatizar o atendimento logístico via LLMs.

4. Segurança & Governança

Protegemos as rotas com JWT/RBAC, usamos Trivy e aplicamos defesas contra Prompt Injection.

Dinâmica da Global Solution (Hackathon)

A Global Solution testará a capacidade de vocês entregarem uma solução **End-to-End**. O que os avaliadores buscam?

  • Organização (Git): Uso de branches/worktrees, README claro (PRD/SDD).
  • Reprodutibilidade (Docker): O projeto deve rodar com um simples docker-compose up.
  • Engenharia AI (RAG): Integração real e inteligente, não apenas um "chamar a API do ChatGPT".
  • Segurança: Falta de segurança (tokens hardcoded, sem RBAC) retira pontos.

Hoje: Faremos um simulado. O laboratório desafiará vocês a subirem o backend (API JWT), e o Serviço AI (RAG Mock) num único arquivo Docker Compose interligado pela mesma network.

Quiz #2 (Retorno do Intervalo)

No contexto de RAG (Retrieval-Augmented Generation), o que garante que o LLM não invente informações (Alucinação)?

Quiz #3

O que acontece se uma aplicação que exige Autenticação JWT for exposta para a internet sem utilizar HTTPS/TLS (Camada 6/7 do OSI)?
  • A Absolutamente nada, o JWT já vem com criptografia avançada que impede roubos.
  • B O servidor irá travar automaticamente usando a porta 443.
  • C O Token JWT trafegará em texto plano, permitindo que um atacante na rede o intercepte (Sniffing) e personifique o usuário.
  • D O JWT só funciona internamente no Docker Compose, logo não é um problema.
