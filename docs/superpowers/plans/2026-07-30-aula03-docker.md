- [ ] **Passo 2: Parametrizar o caminho de dados por variável de ambiente**

Os dois serviços gravam e leem um caminho fixo herdado da Aula 02. Para o ciclo
de volumes funcionar, o caminho precisa ser configurável. Em
`servicos/coletor/server_telemetry.py`, substituir a constante de caminho por:

```python
import os
_PADRAO = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                       "dados", "telemetria.jsonl")
CAMINHO_DADOS = os.environ.get("LOGITECH_DADOS", _PADRAO)
os.makedirs(os.path.dirname(CAMINHO_DADOS), exist_ok=True)
```

O padrão é **relativo ao diretório do serviço**, e não `/dados/...`. Um padrão
absoluto na raiz faz o aluno tomar `PermissionError` ao rodar o serviço solto na
máquina dele. Quem declara o caminho absoluto é o Dockerfile, com
`ENV LOGITECH_DADOS=/dados/telemetria.jsonl`, que é o próprio conceito do ciclo
de volumes: o container decide onde os dados moram, sem recompilar a aplicação.

Varra os dois serviços atrás de caminho antigo cravado, **inclusive dentro de
mensagem de `print`**: uma mensagem de log que cita um caminho que não existe é
pior do que log nenhum, ainda mais numa aula que manda o aluno rodar
`docker logs`.

Em `servicos/gateway/server.js`:

```javascript
const CAMINHO_DADOS = process.env.LOGITECH_DADOS || '/dados/telemetria.jsonl';
```

Trocar todas as referências ao caminho antigo pelas constantes novas.

- [ ] **Passo 1: Escrever o esqueleto com os sete critérios**

Sem dependências externas, só `subprocess`, `json`, `os`, `re`, `sys`, `argparse`.
Cada critério é uma função `etapa_N()` que devolve `(bool, str)`, sendo a string
o diagnóstico exibido quando falha.

```python
#!/usr/bin/env python3
"""Verificador progressivo do laboratorio da Aula 03."""
import argparse, json, os, re, subprocess, sys

RAIZ = os.path.dirname(os.path.abspath(__file__))

def docker(*args):
    """Roda docker e devolve (codigo, stdout). Nunca levanta excecao."""
    try:
        p = subprocess.run(["docker", *args], capture_output=True,
                           text=True, timeout=60)
        return p.returncode, p.stdout.strip()
    except (OSError, subprocess.TimeoutExpired):
        return 1, ""

def ler(caminho):
    p = os.path.join(RAIZ, caminho)
    if not os.path.exists(p):
        return ""
    with open(p, encoding="utf-8") as f:
        return f.read()
```

LIMITE_REDUCAO = 80.0   # ajustar ao valor medido na Tarefa 1

def _estagios_e_usuario(caminho):
    txt = ler(caminho)
